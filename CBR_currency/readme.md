# ETL-пайплайн для загрузки курсов валют ЦБ РФ
[project](https://github.com/ghdena/Portfolio/blob/main/CBR_currency/Currency_from_CBR.py)

### 📌 Цель
Разработать автоматизированный пайплайн для ежедневной загрузки, трансформации и сохранения актуальных курсов валют с официального сайта [ЦБ РФ](https://cbr.ru) 
в базу данных PostgreSQL. Обеспечить надёжное и воспроизводимое пополнение исторических данных.

### 🛠️ Инструменты
- Apache Airflow
- Python
- Pandas
- PostgreSQL

### 📝 Описание проекта
В рамках проекта был создан ETL-пайплайн, который каждый день:
- Определяет последнюю загруженную дату в таблице currency_rates.
- Загружает все пропущенные дни (начиная с 1 января 2013 года или с последней даты в БД).
- Парсит XML-ответ от API ЦБ РФ, извлекает курсы всех валют.
- Трансформирует данные (очистка, приведение типов, переименование колонок).
- Вставляет данные в PostgreSQL.


Схема данных:

```PostgreSQL
CREATE TABLE cbr.currency_rates (
    id SERIAL PRIMARY KEY,
    digital_code VARCHAR(3) NOT NULL,     -- цифровой код валюты
    letter_code CHAR(3) NOT NULL,         -- буквенный код (USD и др.)
    units INTEGER NOT NULL DEFAULT 1,     -- номинал
    currency_name VARCHAR(100) NOT NULL,  -- название валюты
    rate DECIMAL(15, 4) NOT NULL,         -- курс
    rate_date DATE NOT NULL,              -- дата курса
    UNIQUE (rate_date, letter_code)       -- гарантия уникальности (индекс)
);
```

### 📊 Выводы и ценность
Сформирован ежедневный DAG, который загружает курсы всех валют ЦБ РФ начиная с 2013 года. 

**Бизнес-ценность:**
- Автоматизация: исключён ручной сбор курсов валют — экономия времени и исключение человеческого фактора.
- Актуальность данных: курсы загружаются ежедневно после публикации ЦБ РФ.
- Исторический архив: возможность анализировать динамику курсов с 2013 года.
- Готовность к аналитике: данные структурированы и хранятся в реляционной БД, готовы для подключения BI-инструментов (Tableau, Power BI, DataLens).
